# Library Management System

Қазақстан Республикасының Ұлттық академиялық кітапханасының кейбір жұмыс
үдерістеріне сүйеніп жасалған Java OOP оқу жобасы. Бағдарлама кітаптар мен
журналдарды каталогта сақтайды, оқырмандарды тіркейді, материалды беру/қайтару
жазбаларын жүргізеді, кешігуді және оқу үлгісіндегі айыппұлды есептейді.

## Мүмкіндіктер

- кітап, журнал және автор қосу;
- каталогты көру;
- атауы және авторы бойынша іздеу;
- материалдың қолжетімділігін тексеру;
- оқырманды тіркеп, бірегей билет нөмірін беру;
- материалды беру және қайтару;
- белсенді және кешіктірілген берілімдерді көру;
- кешіккен күндер үшін айыппұл есептеу;
- мәліметтерді `data/library-data.bin` файлына сақтау және қайта оқу;
- қазақ тіліндегі консольдік мәзір.

## ООП қағидалары

- **Абстракция:** `LibraryItem` абстрактілі класы.
- **Мұрагерлік:** `Book` және `Magazine` кластары `LibraryItem` класынан мұра алады.
- **Полиморфизм:** `Catalog` ішінде `List<LibraryItem>` сақталады және `getInfo()`
  нақты объект түріне қарай орындалады.
- **Инкапсуляция:** өрістер жабық, ал қолжетімділік күйі `borrow()` және
  `returnToLibrary()` әдістері арқылы ғана өзгереді.
- **Интерфейс:** `Catalog` класы `Searchable` интерфейсін жүзеге асырады.
- **Композиция және байланыстар:** `Loan` оқырман мен материалды байланыстырады,
  ал кешігу болса оның құрамында `Fine` пайда болады.

## Құрылым

```text
src/main/java/kz/library/
├── Main.java
├── exception/   - пәндік қателер
├── model/       - негізгі UML кластары
├── service/     - Catalog, Searchable және LibrarySystem
├── storage/     - файлға сақтау/оқу
└── ui/          - қазақ тіліндегі консольдік мәзір
```

## Талаптар

- JDK 21 немесе одан жаңа нұсқа;
- Windows PowerShell;
- қосымша кітапхана, Maven немесе Gradle қажет емес.

## Іске қосу

PowerShell арқылы жоба бумасында:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```

Дайын ООП сценарийін көрсету:

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1 --demo
```

Тесттерді орындау:

```powershell
powershell -ExecutionPolicy Bypass -File .\test.ps1
```

VS Code қолданылса, Microsoft ұсынған **Extension Pack for Java** кеңейтімін
орнатқаннан кейін Run and Debug бөліміндегі дайын конфигурацияларды таңдауға болады.

## Ескерту

Айыппұл мөлшері (`100 ₸/күн`) тек оқу демонстрациясына арналған. Ол нақты
Ұлттық академиялық кітапхананың ресми ережесін білдірмейді.
